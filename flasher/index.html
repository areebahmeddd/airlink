Airlink

A relay node for Airhop, bitchat-ios and bitchat-android, installed from your browser. You need Chrome or Edge on a desktop and a USB data cable.

Before installing

This installs a release image, and its first boot is permanent. It turns on Secure Boot and flash encryption for good: the board then runs only images signed by this project, updates only over the air from another Airlink node of the same board in Bluetooth range.

Keep it powered through that boot, which can take a minute. To keep a board you can reflash over USB, build the development image from the source instead.

Install

Plug the board in, pick it below, and select Connect.

After installing

Open a serial console at 115200 baud, then:

  1. On a LoRa board, set the region before it transmits: region us, eu, in, anz or sea.
  2. To take Airlink's own updates from other nodes, give it the project's update key: 
    owner a6123922152c32f3e072a72ab9403d8a5810fa3eb05a9a29069fe3421d6945b4 e930e9606543e7b8
  3. reboot applies the settings, and status shows them and what the node is doing.
  4. Before the node leaves your hands, lock yes closes provisioning for good, once the update key is set. Until then anyone with a USB cable can set their own key and lock the node to it.
